# banc App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Private Finanz-PWA „banc“ nach den Designs in `Designideen/PNGs_01`, live unter https://banc.mercao.de.

**Architecture:** Svelte-5-SPA ohne Router (Ansicht im State). Reine Logik (`src/lib/*.ts`) ist UI-frei und mit Vitest getestet; UI-Komponenten rufen nur `ops.ts` (Mutationen) und `calc.ts` (Ableitungen) auf. Persistenz: ein JSON-Dokument pro Profil in Supabase, versioniert gespeichert.

**Tech Stack:** Vite 6, Svelte 5, TypeScript, Vitest, @supabase/supabase-js 2, lucide-svelte (Icons), GitHub Actions → GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-10-27-banc-app-design.md`

## Global Constraints

- Beträge intern in Cent (int); Anzeige `1128.00 €`, negativ `-10.00 €`.
- Monate als `'YYYY-MM'`, Tage als `'YYYY-MM-DD'`; „heute“ immer über injizierbares `today: string` (testbar).
- UI-Texte deutsch, exakt wie in den Designs (z. B. „Eintrag hinzufügen“, „Gruppe löschen?“, „Unbegrenzt“, Listen: „Unlimited“).
- Mobile-first, max. Inhaltsbreite 420 px, zentriert; Hell/Dunkel über `data-theme` auf `<html>`, gespeichert in `localStorage` (`banc-theme`).
- Farben: income `#6f9a8d`, expense `#8e5f86`, danger `#e5371b`.
- Keine Secrets im Repo außer Supabase-URL + Publishable Key (öffentlich gedacht).

## Review Focus

- Betrag mit Komma („2,30“), leer, „-10“ oder Buchstaben → richtig geparst bzw. ✓ deaktiviert (Test in Task 2).
- Wiederkehrender Eintrag über Jahresgrenze (Okt 26 – Feb 27) → zählt in Jan 27, nicht in Mär 27 (Task 2).
- Gelöschte Kategorie/Gruppe → ihre Einträge zählen nirgends mehr, erscheinen im Papierkorb, Wiederherstellen macht alles wieder sichtbar (Task 3).
- Monatsnavigation Dez → Jan wechselt das Jahr (Task 2, `addMonths`).
- Zwei Geräte speichern gleichzeitig → kein stilles Überschreiben, sondern Neu-Laden mit Hinweis (Task 4, manuell geprüft).
